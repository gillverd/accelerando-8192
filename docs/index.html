04 / UNDER THE SURFACE

A visual alphabet.
A precise system.

Not a translation, and not an embedding model. Accelerando-8192 changes how text is represented while keeping the original bytes intact.

01 — TEXT

Break it into pieces.

A custom byte-pair tokenizer uses the first 8,192 mergeable entries from o200k_base, with its original pretokenization rules. All 256 single-byte values are covered.

02 — TOKENS

Make the mapping fixed.

Token ID equals glyph ID. Character 500 always represents token 500, in every message. The full vocabulary exists independently of any song or sentence.

03 — GLYPHS

Give every piece a form.

Each glyph is a distinct connected shape on a compact grid. Horizontal, vertical, and 45-degree strokes preserve the alphabet’s angular character.

8,192 is the vocabulary size, not an embedding dimension. Rotations and reflections may be different glyphs. Distinct shapes are not a claim of equal readability.
